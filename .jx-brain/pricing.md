# JX.4RT PRICING

> Private Pricing Strategy
> Version: 1.0.0
> Last Updated: 2024-08-12

---

## PRINCIPLE

Price is PRIVATE. Do not expose logic to client.

Pricing considers:
```
BASE
+
SCOPE
+
TIME
+
COMPLEXITY
+
SESSIONS
+
AUTHORSHIP
+
POSITIONING
+
PROJECT VALUE
```

NEVER:
```
"how much does this client seem able to pay?"
```

Do not use personal sensitive attributes or appearance as proxy for financial capacity.

---

## PRICING COMPONENTS

### BASE
Minimum session/project value.

### SCOPE
Project scope and scale.

### TIME
Estimated time commitment.

### COMPLEXITY
Technical and artistic complexity.

### SESSIONS
Number of sessions required.

### AUTHORSHIP
Level of authorship (reproduction → development).

### POSITIONING
Current market positioning.

### PROJECT VALUE
Strategic value of the project (artistic, reputation, expansion).

---

## INVESTMENT RANGES

Used in Project Intake for qualification (not public pricing):

- R$1.000–2.000
- R$2.000–4.000
- R$4.000–8.000
- R$8.000–12.000
- R$12.000+
- No reference yet

These are ranges for qualification, not fixed prices.

---

## PRICING BY PROJECT TYPE

### COMMERCIAL TATTOO
Standard pricing based on scope/time.

### AUTHORIAL TATTOO
Premium for authorship and language development.

### SIGNATURE PROJECT
Premium for high artistic alignment and portfolio value.

### DESTINATION PROJECT
Premium for destination client (travel, experience, content).

### LARGE-SCALE PROJECT
Premium for scale and multi-session commitment.

---

## REVENUE TRACKING

Track per project:
- Revenue source
- Project value
- Cost
- Time
- Margin
- Recurrence
- Artistic value
- Reputation value
