## PROJECT TYPES

### COMMERCIAL TATTOO
Relatively simple, execution-oriented.

### AUTHORIAL TATTOO
Developed from JX.4RT language.

### SIGNATURE PROJECT
High complexity, high artistic alignment, high portfolio/reputation potential.

### DESTINATION PROJECT
Client travels specifically for the work.

### LARGE-SCALE PROJECT
Multiple sessions, high investment.

### ORIGINAL ART
Non-tattoo original artwork.

### EDITION
Print or edition work.

### OBJECT
Physical object/product.

### COLLABORATION
Collaborative project.

---

## VALUE DIMENSIONS

### Commercial Value (1-10)
Financial potential and return.

### Artistic Value (1-10)
Artistic merit and language development.

### Reputation Value (1-10)
Impact on positioning and reputation.

### Relationship Value (1-10)
Potential for ongoing relationship.

### Expansion Value (1-10)
Potential for derivative works or expansion.
