## STRATEGIC PRIORITIZATION

### Impact vs Effort Matrix

Evaluate opportunities on:
- **IMPACT**: Potential value (artistic, commercial, reputation, expansion)
- **EFFORT**: Time, complexity, resource requirement

### Value Matrix

Evaluate opportunities on:
- **MONEY**: Financial return
- **ART**: Artistic value
- **REPUTATION**: Reputation value
- **EXPANSION**: Expansion potential

Prioritize opportunities with strong combination of these factors.

---

## CENTRAL ECONOMIC PRINCIPLE

**Strategy**: Extract more value from each unit of artistic language created.

Example flow:
```
MASTER ART
   ↓
TATTOO
   ↓
DOCUMENTATION
   ↓
PORTFOLIO
   ↓
CONTENT
   ↓
PRINT / EDITION
   ↓
COLLABORATION
   ↓
REPUTATION
   ↓
NEW CLIENTS
```

Not every work follows all steps. System identifies which works have expansion potential.

## REVENUE STRATEGY

### Revenue Sources

```
REVENUE
│
├── Tattoo
├── Large-scale tattoo
├── Destination tattoo
├── Original artwork
├── Prints / editions
├── Objects
├── Fashion
├── Art direction
├── Collaborations
├── Licensing
├── Exhibitions
└── Digital / technology projects
```

### Revenue Source Status

Each source has status:
- **EXPLORING**: Initial exploration
- **VALIDATING**: Testing viability
- **ACTIVE**: Currently generating revenue
- **PROVEN**: Established revenue stream
- **PAUSED**: Not currently active

### Metrics

Not just revenue. Track:
- Revenue per hour
- Revenue per project
- Revenue per client
- Revenue by channel
- Revenue by artistic category
- Revenue by project type

## PORTFOLIO INTELLIGENCE

Portfolio not organized only chronologically.

Classify works by:
- Artistic strength
- Commercial strength
- Signature
- Technique
- Body placement
- Visual language
- Project scale
- Client type

**Goal**: Show first the work that best represents desired positioning.

## CONTENT ASSET SYSTEM

Content is also an asset.

A project can generate:
- Final tattoo
- Making of
- Drawing
- Process
- Video
- Photography
- Study
- Editorial
- Case study

Register which content exists. Increases project value without increasing client count.

## DECISION CRITERIA

For any opportunity, answer:

### ART
What am I creating?

### VALUE
What is the artistic value?

### MONEY
How does this generate revenue?

### REPUTATION
How does this increase positioning?

### ASSET
Can this become an asset?

### EXPANSION
Can this open a new opportunity?

### LEARNING
What did we learn?
