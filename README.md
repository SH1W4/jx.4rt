# JX.4RT

Visual language through tattoo.

---

## Overview

JX.4RT is a personal artistic practice developing a unique visual language through tattoo. The project combines refined brutalism with cyberpunk aesthetics to create a distinctive identity in the tattoo space.

## Design Philosophy

### Refined Brutalism

JX.4RT uses a refined brutalist aesthetic characterized by:
- Materiality and precision
- Visual silence and restraint
- Strategic use of negative space
- Editorial typography
- No gratuitous effects

### Visual Identity

- Dark palette with high contrast
- Monospace typography for technical elements
- Sans-serif for body text
- Grid-based layouts
- Minimal animations
